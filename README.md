# 💼 FreelanceHub – Full Stack Freelancer Marketplace

FreelanceHub is a full-stack freelancer marketplace that connects clients with freelancers. Clients can post projects, review applications, hire freelancers, communicate through messaging, manage project progress, and leave reviews after completion.

Freelancers can discover projects, submit proposals, manage applications, communicate with clients, and build their profile and reputation through ratings and reviews.

The application is fully deployed using Render and MongoDB Atlas.

## ✨ Key Features

### 👨‍💼 Client Features

- Client registration and secure login
- Client dashboard
- Create and post projects
- Edit and delete open projects
- View submitted freelancer applications
- Compare freelancer profiles
- Accept or reject applications
- Search for freelancers
- Save favourite freelancers
- Send project invitations
- Message accepted freelancers
- Start projects
- Mark projects as completed
- Leave ratings and reviews

### 👩‍💻 Freelancer Features

- Freelancer registration and secure login
- Freelancer dashboard
- Create and edit freelancer profile
- Browse available projects
- Search and filter projects
- Submit project applications
- Track application status
- Withdraw pending applications
- Receive client invitations
- Accept or decline invitations
- Communicate with clients
- View project progress
- Receive ratings and reviews

### 💬 Messaging

- Client–freelancer messaging
- Project-based conversations
- Conversation history
- Unread message tracking
- Communication between accepted project participants

### ⭐ Reviews & Ratings

- Clients can review freelancers after project completion
- Star-based rating system
- Written feedback
- Reviews displayed on freelancer profiles

## 🔄 Project Workflow

The marketplace supports the complete freelancer hiring workflow:

Client posts a project  
↓  
Freelancer discovers the project  
↓  
Freelancer submits an application  
↓  
Client reviews applications  
↓  
Client accepts a freelancer  
↓  
Client and freelancer communicate  
↓  
Project starts  
↓  
Project is completed  
↓  
Client leaves a rating and review
